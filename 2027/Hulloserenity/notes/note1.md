##**Shell**
1.###*终端、SHell与命令*
-终端输入命令，由Shell解释，再交给程序执行。

2.###*Shell命令的结构*
-**命令【选项】【参数】**
-| 结构 | 示例 | 意义 |
 | - | - | - |
 | **命令** | ls | **做什么** |
 | **选项** | -la | **怎样执行**，其中“-l”详细信息，“-a”含隐藏项 |
 | **参数** | ～/projects | **操作哪个对象**，这里是目标目录 |

3.###***当前位置与目录切换***
-| 命令 | 作用 |
 | - | - |
 | pwd | 显示当前目录 |
 | ls | 列出目录内容 |
 | cd 目录 | 进入指定目录 |
 | cd .. | 返回上一级 |
 | cd ~ | 返回家目录 |

4.###***文件和目录操作***
-| 命令 | 作用 | 示例 |
 | - | - | - |
 | **mkdir -p** | 创建目录，允许补齐父目录 | mkdir -p/linux\_dome |
 | **touch** | 创建空文件/更新时间 | touch hello.txt |
 | **cp** | 复制文件 | cp hello.txt hello-copy.txt |
 | **mv** | 移动或重命名 | mv hello-copy.txt backup.txt |
 | **rm** | 删除文件 | rm backup.txt |
 | **cat/less** | 直接查看/分页查看 | cat hello.txt |
 
5.###***Shell的四种常用组合***
-**变量**：    name="RM";echo"$name"   
-**重定向**：  echo"hello"\>hello.txt     “>”覆盖写入；“>>”追加到文件末尾
-**管道**：    ls -la |grep txt           将输出交给下一个程序（筛选特定文件）
-**条件连接**：mkdir -p demo && cd demo   前一条成功后，再执行下一条

6.###*陌生命令的帮助入口*
-| 命令 | 作用 |
 | - | - |
 | ls --help | 快速查看选项和用法 |
 | man ls | 打开手册，按q退出 |

##**Vim**
1.###*Vim模式*
Vim有三种模式，分别为普通模式、插入模式、命令行输入。
-普通模式用于浏览查找文本。
-插入模式用于修改文本。
-命令行输入用于保存或退出。
普通模式按i进入插入模式；按:进入命令行输入。
按esc返回普通模式。

2.###***必备按键***
-*普通模式*
-| 按键 | 操作 |
 | - | - | 
 | h j k l | 左/下/上/右 |
 | dd | 删除当前行 |
 | yy/p | 复制当前行 |
 | u | 撤销 |
 | /word | 搜索 word |
-*命令行输入*
-:w 保存 :q 退出 :wq 保存退出 :q! 放弃修改退出

##**git && github**
1.###*git与github的分工*
-**git：本地版本控制**
 -记录每次提交
 -比较修改、查看历史
 -为新功能创建分支
-**github：远程托管与协作**
 -托管git仓库
 -通过PR讨论和评审
 -合并团队认可的修改

2.###*git*
-git的四个位置
 -**工作区**：正在编辑的文件。通过***git add***转移到暂存区。
 -**暂存区**：本次提交的内容清单。通过***git commit***提交到本地仓库。
 -**本地仓库**：已记录的提交历史。通过***git push***推送到github远程仓库。
 -**github远程仓库**：远程保存的提交历史。
 
-常用命令
 -**git clone <仓库地址>**：下载仓库及提交历史
 -**git status**：查看当前分支和文件状态
 -**git diff**：查看尚未暂存的修改
 -**git log-oneline**：用简短格式查看提交历史
 -**git switch -c feature/hello**：创建并切换到功能分支
 -**git add hello.txt**：暂存指定文件
 -**git commit -m "Add greeting"**：记录一次本地提交
 -**git push -u origin feature/hello**：推送并建立跟踪关系
 -**git switch main**：切回主分支
 -**git push**：获取并整合当前分支的远程更新

3.###*github*
工作流程：
  团队仓库->个人Fork（仓库副本）-> clone到本地电脑 -> feature 分支 -> add -> commit -> push ->个人Fork接收 -> PR -> Review -> Merge
